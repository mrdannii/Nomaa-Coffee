# NOMAA Coffee

Next.js 15 App Router, TypeScript, Tailwind CSS 4, Framer Motion, Lucide, and Embla Carousel.

Run `npm install` then `npm run dev`. Run `npm run build` to generate the static `out/` deployment. Next Image is used with static-compatible image delivery; enable a Next image optimization server when moving to a server deployment.

Product copy, image positions, lifestyle images, and illustrative locations are in `data/products.ts`. Replace sample addresses, hours, and social links before a public launch. Newsletter validation and coffee selection are frontend demonstrations; no backend is claimed or connected.

Product photography was generated with the built-in ImageGen tool. Prompt briefs: five isolated transparent NOMAA iced drink cups in one row, caramel/mocha/vanilla/matcha/brown sugar; transparent hand-held marbled NOMAA iced latte with coffee splash. Final assets: `public/images/coffee-lineup.png`, `public/images/coffee-story.png`. Lifestyle images are downloaded Unsplash photographs. Motion respects reduced-motion preferences. Carousels support keyboard arrows, and mobile product browsing supports swipes.
